# 算法说明

## 形态分类（规则 + 可解释理由）

特征：ADF p 值、Spearman 趋势强度、零值占比、非零连续段数、变点分数、主周期、方差稳定性。

规则按以下顺序短路（避免重叠判据互相吞掉）：

1. `sparse_event`：零值占比 ≥ 60% 且非零连续段很少
2. `high_zero_ratio`：零值占比 ≥ 60%（非稀疏事件）
3. `periodic`：检测到可信的主周期
4. `step`：变点分数高且趋势弱
5. `stationary`：ADF 拒绝单位根且趋势弱
6. `trending`：其余

推荐表把形态映射到首选/备选检测器，只作为起点，不替代回测。

## 周期估计：FFT 粗定位 + ACF 验证

周期估计是形态分类与 Seasonal / STL 检测器的共同上游。它有三处关键设计：

1. **FFT 粗定位 + ACF 验证**。只用 ACF 会有两个问题：lag 上限写死时
   （原来 200）根本看不到长周期——5min 粒度的日周期是 288 点、周周期 2016 点；
   而且 ACF 峰的位置有 ±1 的误差，**相位分组时 ±1 会让基线整体错位**。
   现在用 FFT（补零 + 抛物线插值）定位置，ACF 只用来验证「这附近真有周期」。
2. **候选周期范围按时间表达**（默认 1 小时 ~ 30 天），换算成点数。
   同一个「一天」在 5min / 15min / 1h 粒度下都能被认出来。
3. **置信度 + 安全回退**。纯噪声里也能挑出一个「像周期」的峰，所以
   「检出了」与「该用」是两回事：置信度低于 0.35 就不用；
   周期装不下两个周期（相位分组每相位至少 2 个点）也回退到默认周期。

实测（合成集 20 条 periodic 序列，5min 粒度，真值周期 ∈ {24, 48}）：

| 周期来源 | 平均 F1 |
|---|---|
| 真值周期（上界） | 0.5881 |
| 旧实现（仅 ACF） | 0.5800 |
| **新实现（FFT + ACF）** | **0.5881** |

新实现**完全追平了「用真值周期」的上界**，5 条变好、0 条变差。

自相关用 FFT 卷积计算（O(n log n)），长序列上比直接相关快一个量级。

## 检测器与分数语义

| 检测器 | score_type | 分数 | 默认阈值 | 备注 |
|---|---|---|---|---|
| IQR | zscore | `|x - median| / IQR` | 2.5 | 支持滚动窗口 |
| MAD | zscore | `|x - median| / (1.4826·MAD)` | 3.5 | 对尖峰稳健 |
| ZScore | zscore | `|x - mean| / std` | 3.0 | 经典基线 |
| Seasonal | zscore | 同相位组内 `|x - median| / MAD` | 2.5 | 周期自动检测（FFT + ACF） |
| STLResidual | residual_ratio | `|resid| / resid_MAD` | 3.5 | STL 需 statsmodels；周期自动检测 |
| DeseasonalizedIQR | zscore | 去线性趋势后的 IQR 分数 | 2.5 | 适合趋势/阶梯 |
| ChangePoint | prob | `1 - p`（滑窗双样本 t 检验） | 0.99 | 高召回、低精度 |
| EventCount | prob | `P(泊松基线 < 实际窗口计数)` | 0.99 | 适合稀疏事件 |
| TCN / LSTM | prob | 重构误差 min-max 到 `[0,1]` | 0.5 | 只用干净序列训练 |
| Chronos | prob | 预测区间越界程度 / 区间宽度 | 0.5 | 权重缺失时跳过 |

## 阈值搜索

- 在分数语义对应的范围内均匀取 200 个候选；
- 逐候选计算点级 P/R/F1，取 F1 最大；并列取召回更高；
- 无真值时直接抛 `ValueError`，不允许“无监督调参”混入评测。

## 指标

- **点级**：`precision_recall_f1(pred, truth)`，分母为 0 时精确率记 0。
- **点调整**：真值区间后 `delay` 点内只要出现预测，整个区间算命中，缓解告警延迟。
- **区间级**：按预测/真值区间与对方的重叠长度占比计算 P/R，`beta=2` 更偏召回；过度检测会拉低精确率。
- **IoU**：区间交并比，用于单区间诊断。
- **检测延迟**：首次预测相对首次真值的位置差，未检出返回 -1。

## Bad Case 归因

对每个误报/漏报连续段输出：形态、位置（前 10%/中段/后 10%）、连续性（孤立点/连续段）、该点分数的序列分位、可读原因。用于把“F1 低”翻译成“哪类形态、哪个位置、分数够不够高”。
