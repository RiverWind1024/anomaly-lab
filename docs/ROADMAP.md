## v2 候选池（不在 v1 范围）

- 流式 / 在线检测（滑窗 + 增量统计量）
- 误报抑制策略（按异常方向 / 时段 / 偏离度匹配）—— 对应现职工作的"反馈抑制"
- 机器学习形态分类器（对照规则版，评估可解释性 vs 准确率的取舍）
- 零值 / 稀疏事件的专门建模（泊松、负二项）
- 多变量异常（NASA SMAP/MSL 遥测）
- 分布漂移检测（训练/服务分布不一致）
- 接入 Prometheus / OpenTelemetry 真实监控源 —— **注意：这会拉长红线边界，需重新评估合规**
